# Programação Web

Repositório de estudos e atividades da disciplina **Programação Web**. Aqui estão reunidos exercícios feitos ao longo das aulas e projetos práticos, desde os primeiros documentos HTML até páginas com estilos e interações em JavaScript.

O conteúdo ainda está em desenvolvimento: novas aulas, atividades e projetos poderão ser adicionados durante a disciplina.

## Como visualizar

As páginas são feitas com HTML, CSS e JavaScript, sem etapa de compilação. Abra o arquivo `index.html` da pasta desejada em um navegador. Para uma experiência mais consistente, também é possível servir a pasta com uma extensão ou ferramenta de servidor local, como o Live Server do VS Code.

Algumas páginas carregam fontes do Google Fonts e, nesse caso, precisam de conexão com a internet para exibi-las.

## Tecnologias

- HTML
- CSS
- JavaScript
